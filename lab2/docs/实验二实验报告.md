# Web 信息处理与应用实验二：电影知识图谱子图抽取与链接预测

**小组成员：JL251112401 邓刚**

## 一、实验任务

从 Freebase 电影图谱中抽取至少含 3,000 个实体的子图，在课程框架中补全尾实体负采样和 TransE 模型。给定一部电影及一种关系，例如“电影 A 的语言是？”，模型需要在子图的全部实体中为正确答案排序。

## 二、子图抽取与数据划分

以流式方式读取课程提供的 `freebase_douban.gz`。保留头尾均为 Freebase 命名空间下 `m.` 或 `g.` 实体、关系属于 `film.film.*` 的三元组。以 2025 为种子对电影头实体的 MID 计算 BLAKE2b 哈希，取哈希值最小的 1,600 部电影，收集它们符合条件的出边并去重。实体和关系分别排序，从 0 开始连续编号。

| 子图统计 | 数量 |
| --- | ---: |
| 不同实体（含电影及相邻实体） | 4,551 |
| 原始关系 | 38 |
| 去重后三元组 | 9,058 |
| 训练 / 验证 / 测试三元组 | 7,248 / 905 / 905 |

打乱三元组后按约 8∶1∶1 划分。留出一条边时，检查两个端点和关系在训练集中是否仍有记录。三个集合互不重叠。训练时为每条训练边加入一条独立编号的反向边，因此用于采样的训练图有 14,496 条有向边、76 种有向关系。磁盘上的三份数据保留原始方向，每行以空格分隔头实体、关系和尾实体的整数编号。

## 三、TransE 实现与评估

用 32 维向量分别表示实体和关系。对向量做 L2 归一化后，三元组距离为 `d(h,r,t) = ‖h + r − t‖₂`，距离越小排名越靠前。负采样固定头实体和关系，随机替换尾实体，排除训练图中该查询的已知真尾实体。对一个正例和一个负例，排序损失为 `softplus(d正 − d负)`；当正例距离小于负例距离时，损失随两者间距增大而减小。

基础模型使用 Adam，学习率为 0.001，L2 正则系数为 0.0001，批大小为 2,048。共训练 40 轮，每 5 轮在验证集计算 MRR，选中第 40 轮。实验使用 CPU，随机种子为 2025。

验证与测试采用课程框架的过滤排名。对每个查询，在全部 4,551 个实体中保留当前目标，并屏蔽三个集合中同一头实体、同一关系的其他已知真尾实体。正确答案的排名为“距离严格小于它的候选数加 1”。模型拟合和属性统计使用训练集；选择轮数和排序参数使用验证集 MRR。下列对照沿用同一划分，后续方法开发时已知前一方法的测试成绩。

## 四、改进方法

- **B：混合负采样与关系频率、邻居排序。** 每轮遍历打乱后的训练边，批大小改为 512。负例候选有一半概率取自同一关系在训练中出现过的尾实体，使模型也能遇到类型相近的错误答案。最多训练 60 轮，每 10 轮验证一次，第 40 轮最佳。排序时结合训练中的尾实体频率和其他相似电影的属性。以已知属性计算加权余弦相似度，按相似度平方计票。频率平滑项为 0.1，邻居票数权重为 0.3，组合先验的对数权重为 0.15。
- **C：加入电影上下文。** 在 B 的基础上，按关系拟合逻辑回归，用电影在其他关系下的已知属性预测尾实体。对于出现至少 3 次的候选，用对数条件概率与对数先验概率的差修正得分，验证选定权重为 0.15。
- **D：加入属性共现。** 在 C 的基础上，将训练事实组成“电影 ×（关系，尾实体）”矩阵，只保留出现至少两次的属性。用带 L2 正则的 EASE 线性模型预测候选属性，系数矩阵对角线设为零，避免属性预测自身。验证选定的正则强度和共现分数权重均为 3。

## 五、结果与分析

MR 是正确答案的平均排名，越低越好。MRR 是排名倒数的平均值，对靠前的答案更敏感。Hits@K 是正确答案进入前 K 的查询比例。下表除“验证 MRR”外，均基于相同的 905 条测试查询。

| 方法 | 验证 MRR | 测试 MR ↓ | 测试 MRR ↑ | Hits@5 | Hits@10 | 前十命中数 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A　基础 TransE | 0.2432 | 116.61 | 0.2544 | 36.24% | 49.94% | 452 |
| B　混合采样与邻居排序 | 0.5284 | **48.18** | 0.5370 | 68.84% | 77.02% | 697 |
| C　再加上下文 | 0.5381 | 51.73 | 0.5414 | 67.62% | 77.24% | 699 |
| D　再加属性共现 | **0.5526** | 51.63 | **0.5617** | **69.50%** | **78.01%** | **706** |

**基础模型对不同查询的表现差异较大。** 在查询 `(g.120vyqy4, film.film.language, ?)` 时，正确语言实体 `m.04306rv` 排第 1；在 `(m.0jwmwgc, film.film.music, ?)` 中，正确尾实体 `m.01x6v6` 排第 861。基础模型的中位排名是 11，平均排名却为 116.61，说明少数靠后的答案显著拉高了均值。

**增益主要出现在 A 到 B。** 验证集上，调整采样和批大小后，仅用 TransE 距离排序，MRR 从 0.2432 升至 0.4137；再加入关系频率和邻居信息，分别达到 0.4948 和 0.5284。测试集中的类型、国家和语言查询共 761 条，占 84.1%。单独按训练集内该关系的尾实体频率排序，测试 Hits@10 已有 63.43%（同频按编号排序），说明高频答案本身就是较强的基线。B 在类型、国家、语言上的 Hits@10 分别为 73.77%、87.80%、94.74%，但在 46 条电影节查询中仍只命中 4 条。

**后两项改动的收益较小。** C 比 B 多命中 2 条前十查询，但 Hits@5 下降了 1.22 个百分点；D 又多命中 7 条，并将 Hits@5 提升至 69.50%。综合评分相对基础 TransE 多命中 254 条前十查询。结论限于这一电影子图和一次划分；训练集覆盖全部实体，因此这些成绩反映的是已见实体之间缺失链接的预测能力。

## 六、复现与结果文件

使用 Python 3.13.9、PyTorch 2.9.1（CPU）、NumPy 2.3.5、pandas 2.3.3、SciPy 1.18.1、scikit-learn 1.9.1 和 threadpoolctl。在 `lab2` 根目录运行：

| 任务 | 命令 |
| --- | --- |
| 从已有的三份数据训练并测试课程 TransE | `python framework/main_kg.py` |
| 复现表中 A 至 D 的对照和选参，更新结果文件 | `python scripts/run_optimizations.py` |
| 从原始压缩包重新抽取、编号、划分（已提供划分结果） | `python scripts/prepare_data.py` |

`data/freebase/` 只存放 `train.txt`、`valid.txt`、`test.txt`。编号对照表和子图统计位于 `data/metadata/`。实验输出位于 `results/`：

- `metrics.tsv`：四组方法的验证 MRR 和测试指标，对应结果表。
- `predictions.tsv`：各方法对 905 条测试查询的首选实体和正确答案排名，可结合编号对照表查看样例。
- `final_model.pth`：最终方案的嵌入参数及排序超参数；邻居、逻辑回归与共现统计由训练集计算。
